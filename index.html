HOE WERKT HET?
1
Eén persoon maakt het spel aan
Kies een speltype, pas het bord aan en voer teamnamen in. Je krijgt een 6-letterige code.
2
Anderen doen mee met de code
Elke speler opent de app, tikt op Meedoen met code en voert de code in. Kies een team en je naam.
3
De host start het spel
Zodra iedereen in de lobby zit, kiest de host ook een team en tikt op Spel starten.
4
Claim vakjes — maak een foto als bewijs
Tik op een vakje, voltooi de opdracht en maak een foto. Het vakje kleurt in de kleur van jouw team.
5
Win met een rij vol of de meeste vakjes
Vul een rij, kolom of diagonaal → direct gewonnen! Loopt de timer af? Het team met de meeste vakjes wint.
